Supporto MTP/WPD Nativo

Legge direttamente i dispositivi Apple collegati via cavo USB senza bisogno di driver complessi o configurazioni noiose.

Organizzazione Automatica

Ordina e suddivide automaticamente le foto ed i video in sottocartelle basate sulla data di scatto (AAAA-MM-DD).

Filtri

Separa facilmente Foto, Video e scatti in formato RAW prima di avviare il trasferimento.

Sicuro e Privato

Funziona al 100% offline. I tuoi dati non passano mai da server esterni o servizi cloud. Tutto rimane sul tuo dispositivo.

Come funziona

1

Collega l'iPhone al PC

Sblocca l'iPhone, collegalo al computer e, se richiesto, premi "Autorizza questo computer".
Su Windows assicurati di aver installato Dispositivi Apple dal Microsoft Store.

2

Avvia la Scansione

Apri BananaTransfer e premi il pulsante "Scansiona". L'app troverà automaticamente tutti i file sul dispositivo.

3

Scegli e Trasferisci

Seleziona i file che vuoi salvare, la cartella di destinazione e avvia il trasferimento.


Altre funzionalità

  • Gestione automatica dei duplicati: scegli se Rinominare, Saltare o Sovrascrivere i file
  • Scegli se salvare i file nelle cartelle divise per AAAA:MM:GG oppure AAAA:MM
  • Possibilità di convertire le immagini .HEIC in .JPEG
  • Converti facilmente grossi video in .mp4 (H264)
  • Decidi se eliminare i file dal dispositivo dopo il trasferimento
